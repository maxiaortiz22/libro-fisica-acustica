# Plantilla conceptual para una unidad

Esta plantilla es adaptable. No agregar secciones vacías ni forzar todas las partes.

```tex
\chapter{Unidad N: Título}
\label{chap:unidad-n}

\section{Propósito y resultados de aprendizaje}
% Explicar por qué importa y qué podrá hacer el estudiante.

\section{Conocimientos previos}
% Recordatorio breve y referencias a capítulos anteriores.

\section{Situación introductoria}
% Fenómeno, pregunta o problema que motive la unidad.

\section{Primer concepto central}
\subsection{Explicación cualitativa}
\subsection{Magnitudes y unidades}
\subsection{Modelo matemático}
\subsection{Ejemplo resuelto}

\section{Segundo concepto central}
% Repetir la progresión cuando corresponda.

\section{Relación con Fonoaudiología}
% Aplicaciones reales y alcance de la conexión.

\section{Errores frecuentes}
% Confusiones típicas y forma de corregirlas.

\section{Síntesis}
% Relaciones principales y límites de aplicación.

\section{Ejercicios de autoevaluación}
% Conceptuales, numéricos, gráficos y aplicados.

\section{Glosario}
% Solo términos realmente nuevos.

\section{Recursos y referencias}
```

## Resultados de aprendizaje

Usar verbos observables, por ejemplo:

- distinguir;
- calcular;
- interpretar;
- justificar;
- comparar;
- estimar;
- representar;
- relacionar.

Evitar objetivos vagos como “comprender completamente” sin indicar qué evidencia demostraría esa comprensión.

## Progresión de ejercicios

1. Reconocimiento de conceptos.
2. Conversión de unidades y cálculo directo.
3. Problema de varios pasos.
4. Interpretación de una figura o medición.
5. Aplicación a un caso fonoaudiológico.
6. Pregunta integradora o de justificación.
