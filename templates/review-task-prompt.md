# Prompt base para revisar una unidad

```text
$acoustic-book-review

Revisá [UNIDAD / SECCIÓN] en estos modos:
- científico;
- curricular;
- pedagógico;
- editorial.

Primero entregá un informe sin modificar archivos. Clasificá los hallazgos como críticos, mayores, moderados o menores. Para cada uno indicá ubicación, problema, motivo, corrección propuesta y necesidad de fuente.

Prestá especial atención a:
- magnitudes y unidades;
- factores 10/20 en niveles;
- diferencias entre presión, intensidad y potencia;
- diferencias entre frecuencia, pitch, SPL y sonoridad;
- afirmaciones sobre oído medio, cóclea y pruebas auditivas;
- correspondencia con el programa.
```
