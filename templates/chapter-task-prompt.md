# Prompt base para ampliar una unidad

```text
$acoustic-book-authoring

Trabajá sobre [UNIDAD / SECCIÓN].

Objetivo de la tarea:
[DESCRIBIR EL RESULTADO ESPERADO]

Alcance:
- Conservá la estructura y la voz del manuscrito.
- Compará la sección con el mapa curricular.
- Leé las secciones adyacentes para evitar repeticiones.
- Corregí errores científicos que encuentres dentro del alcance.
- Agregá ejemplos, ejercicios y figuras solo cuando aporten al objetivo.
- Marcá afirmaciones que necesiten una fuente primaria.
- Compilá y validá el libro al finalizar.

Antes de editar, presentá un plan breve y una lista de brechas detectadas.
```
